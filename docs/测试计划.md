# Pascal-S 编译器测试计划

## 1. 测试概述

### 1.1 测试目标
- 验证编译器各模块功能的正确性
- 确保生成的C代码语义等价于原Pascal-S代码
- 发现并修复潜在的Bug和缺陷
- 验证编译器的性能和稳定性

### 1.2 测试范围
- 词法分析模块
- 语法分析模块
- 语义分析模块
- 代码生成模块
- 错误处理机制
- 端到端集成测试

### 1.3 测试策略
- **单元测试**: 测试各个独立模块
- **集成测试**: 测试模块间的协作
- **系统测试**: 测试完整的编译流程
- **回归测试**: 确保修改不影响已有功能
- **性能测试**: 验证编译速度和资源使用

### 1.4 测试环境
- **操作系统**: Windows 10/11, Ubuntu 20.04+, macOS 11+
- **编译器**: GCC 9.0+, Clang 10.0+, MSVC 2019+
- **测试框架**: Google Test (C++)
- **内存检测**: Valgrind (Linux), Dr. Memory (Windows)
- **覆盖率工具**: gcov/lcov

#### 3.3.2 测试脚本示例
```bash
#!/bin/bash
# run_tests.sh

for test_file in integration/*.pas; do
    echo "Testing $test_file..."
    
    # 编译Pascal到C
    ./pascal-compiler $test_file -o temp.c
    
    # 编译C代码
    gcc temp.c -o temp.out
    
    # 运行并比较输出
    ./temp.out > actual_output.txt
    expected_output="${test_file%.pas}.expected"
    
    if diff -q actual_output.txt $expected_output > /dev/null; then
        echo "PASS"
    else
        echo "FAIL"
    fi
done
```
