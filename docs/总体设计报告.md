# Pascal-S 编译器总体设计报告

## 1. 系统架构设计

### 1.1 总体架构
本编译器采用经典的多阶段编译器架构，将编译过程分为以下几个独立模块：

```
Pascal-S源代码
      ↓
  词法分析器 (Lexer)
      ↓
   Token流
      ↓
  语法分析器 (Parser)
      ↓
  抽象语法树 (AST)
      ↓
  语义分析器 (Semantic Analyzer)
      ↓
  标注的AST + 符号表
      ↓
  代码生成器 (Code Generator)
      ↓
   C语言代码
      ↓
  C编译器 (GCC/Clang/MSVC)
      ↓
   可执行文件
```

### 1.2 模块划分

#### 1.2.1 核心模块
- **词法分析模块 (Lexer)**: 将源代码转换为Token流
- **语法分析模块 (Parser)**: 构建抽象语法树
- **语义分析模块 (Semantic Analyzer)**: 类型检查和符号表管理
- **代码生成模块 (Code Generator)**: 生成C语言代码

#### 1.2.2 辅助模块
- **错误处理模块 (Error Handler)**: 统一的错误报告机制
- **符号表模块 (Symbol Table)**: 管理标识符信息
- **类型系统模块 (Type System)**: 类型表示和检查
- **工具模块 (Utilities)**: 字符串处理、内存管理等

### 1.3 技术选型

| 组件 | 技术选择 | 说明 |
|------|---------|------|
| 实现语言 | C++ | 面向对象，支持STL |
| 构建工具 | CMake | 跨平台构建 |
| 测试框架 | Google Test | 单元测试 |
| 版本控制 | Git | 代码管理 |
| 文档工具 | Doxygen | API文档生成 |

## 2. 详细模块设计

### 2.1 词法分析器 (Lexer)

#### 2.1.1 功能描述
将Pascal-S源代码字符流转换为Token流，识别关键字、标识符、常量、运算符等。

#### 2.1.2 数据结构

```cpp
// Token类型枚举
enum class TokenType {
    // 关键字
    PROGRAM, BEGIN, END, VAR, CONST, TYPE,
    PROCEDURE, FUNCTION, IF, THEN, ELSE,
    WHILE, DO, REPEAT, UNTIL, FOR, TO, DOWNTO,
    ARRAY, OF, RECORD,
    INTEGER, REAL, CHAR, BOOLEAN,
    DIV, MOD, AND, OR, NOT,
    
    // 标识符和常量
    IDENTIFIER,
    INTEGER_LITERAL,
    REAL_LITERAL,
    CHAR_LITERAL,
    STRING_LITERAL,
    
    // 运算符和分隔符
    PLUS, MINUS, MULTIPLY, DIVIDE,
    ASSIGN, EQUAL, NOT_EQUAL,
    LESS, LESS_EQUAL, GREATER, GREATER_EQUAL,
    LPAREN, RPAREN, LBRACKET, RBRACKET,
    DOT, COMMA, SEMICOLON, COLON,
    
    // 特殊
    END_OF_FILE,
    ERROR
};

// Token结构
struct Token {
    TokenType type;
    std::string lexeme;      // 原始文本
    int line;                // 行号
    int column;              // 列号
    
    // 字面量值
    union {
        int intValue;
        double realValue;
        char charValue;
    } value;
};

// 词法分析器类
class Lexer {
private:
    std::string source;      // 源代码
    size_t position;         // 当前位置
    int line;                // 当前行号
    int column;              // 当前列号
    
    char currentChar();
    char peekChar();
    void advance();
    void skipWhitespace();
    void skipComment();
    
    Token scanIdentifierOrKeyword();
    Token scanNumber();
    Token scanString();
    Token scanChar();
    
public:
    Lexer(const std::string& source);
    Token nextToken();
    std::vector<Token> tokenize();
};
```

#### 2.1.3 关键算法

**状态机识别标识符和关键字**:
```cpp
Token Lexer::scanIdentifierOrKeyword() {
    std::string lexeme;
    int startLine = line;
    int startColumn = column;
    
    // 读取字母和数字
    while (isalnum(currentChar()) || currentChar() == '_') {
        lexeme += currentChar();
        advance();
    }
    
    // 检查是否为关键字
    static const std::map<std::string, TokenType> keywords = {
        {"program", TokenType::PROGRAM},
        {"begin", TokenType::BEGIN},
        {"end", TokenType::END},
        // ... 其他关键字
    };
    
    auto it = keywords.find(lexeme);
    TokenType type = (it != keywords.end()) ? it->second : TokenType::IDENTIFIER;
    
    return Token{type, lexeme, startLine, startColumn};
}
```

**数字识别（支持整数和实数）**:
```cpp
Token Lexer::scanNumber() {
    std::string lexeme;
    bool isReal = false;
    
    // 读取整数部分
    while (isdigit(currentChar())) {
        lexeme += currentChar();
        advance();
    }
    
    // 检查小数点
    if (currentChar() == '.' && isdigit(peekChar())) {
        isReal = true;
        lexeme += currentChar();
        advance();
        
        // 读取小数部分
        while (isdigit(currentChar())) {
            lexeme += currentChar();
            advance();
        }
    }
    
    // 检查科学计数法
    if (currentChar() == 'e' || currentChar() == 'E') {
        isReal = true;
        lexeme += currentChar();
        advance();
        
        if (currentChar() == '+' || currentChar() == '-') {
            lexeme += currentChar();
            advance();
        }
        
        while (isdigit(currentChar())) {
            lexeme += currentChar();
            advance();
        }
    }
    
    Token token;
    token.lexeme = lexeme;
    token.type = isReal ? TokenType::REAL_LITERAL : TokenType::INTEGER_LITERAL;
    
    if (isReal) {
        token.value.realValue = std::stod(lexeme);
    } else {
        token.value.intValue = std::stoi(lexeme);
    }
    
    return token;
}
```

#### 2.2.4 关键解析算法

**表达式解析（处理运算符优先级）**:
```cpp
// 表达式 = 简单表达式 [关系运算符 简单表达式]
std::unique_ptr<ExprNode> Parser::parseExpression() {
    auto left = parseSimpleExpr();
    
    // 关系运算符: =, <>, <, <=, >, >=
    if (match(TokenType::EQUAL) || match(TokenType::NOT_EQUAL) ||
        match(TokenType::LESS) || match(TokenType::LESS_EQUAL) ||
        match(TokenType::GREATER) || match(TokenType::GREATER_EQUAL)) {
        
        Token op = tokens[current - 1];
        auto right = parseSimpleExpr();
        
        auto binary = std::make_unique<BinaryExprNode>();
        binary->op = tokenTypeToBinaryOp(op.type);
        binary->left = std::move(left);
        binary->right = std::move(right);
        return binary;
    }
    
    return left;
}

// 简单表达式 = [+|-] 项 {加法运算符 项}
std::unique_ptr<ExprNode> Parser::parseSimpleExpr() {
    // 处理一元正负号
    std::unique_ptr<ExprNode> expr;
    if (match(TokenType::PLUS) || match(TokenType::MINUS)) {
        Token op = tokens[current - 1];
        auto operand = parseTerm();
        
        if (op.type == TokenType::MINUS) {
            auto unary = std::make_unique<UnaryExprNode>();
            unary->op = UnaryExprNode::Operator::NEG;
            unary->operand = std::move(operand);
            expr = std::move(unary);
        } else {
            expr = std::move(operand);
        }
    } else {
        expr = parseTerm();
    }
    
    // 处理加法运算符: +, -, or
    while (match(TokenType::PLUS) || match(TokenType::MINUS) || 
           match(TokenType::OR)) {
        Token op = tokens[current - 1];
        auto right = parseTerm();
        
        auto binary = std::make_unique<BinaryExprNode>();
        binary->op = tokenTypeToBinaryOp(op.type);
        binary->left = std::move(expr);
        binary->right = std::move(right);
        expr = std::move(binary);
    }
    
    return expr;
}

// 项 = 因子 {乘法运算符 因子}
std::unique_ptr<ExprNode> Parser::parseTerm() {
    auto expr = parseFactor();
    
    // 乘法运算符: *, /, div, mod, and
    while (match(TokenType::MULTIPLY) || match(TokenType::DIVIDE) ||
           match(TokenType::DIV) || match(TokenType::MOD) ||
           match(TokenType::AND)) {
        Token op = tokens[current - 1];
        auto right = parseFactor();
        
        auto binary = std::make_unique<BinaryExprNode>();
        binary->op = tokenTypeToBinaryOp(op.type);
        binary->left = std::move(expr);
        binary->right = std::move(right);
        expr = std::move(binary);
    }
    
    return expr;
}
```

```cpp
void SemanticAnalyzer::visit(AssignStmtNode* node) {
    // 检查左值
    node->target->accept(*this);
    TypeInfo* targetType = node->target->type;
    
    // 检查右值
    node->value->accept(*this);
    TypeInfo* valueType = node->value->type;
    
    // 类型兼容性检查
    if (!checkTypeCompatibility(targetType, valueType)) {
        errorHandler.error(
            "Type mismatch in assignment: cannot assign " +
            valueType->toString() + " to " + targetType->toString()
        );
    }
}

void SemanticAnalyzer::visit(BinaryExprNode* node) {
    // 分析左右操作数
    node->left->accept(*this);
    node->right->accept(*this);
    
    TypeInfo* leftType = node->left->type;
    TypeInfo* rightType = node->right->type;
    
    // 推断表达式类型
    node->type = inferBinaryExprType(node->op, leftType, rightType);
    
    if (node->type == nullptr) {
        errorHandler.error(
            "Invalid operand types for operator: " +
            leftType->toString() + " and " + rightType->toString()
        );
    }
}
```

#### 2.4.3 代码生成示例

```cpp
void CodeGenerator::visit(ProgramNode* node) {
    // 生成头文件
    generateIncludes();
    emitLine("");
    
    // 生成全局变量声明
    for (auto& decl : node->declarations) {
        if (auto varDecl = dynamic_cast<VarDeclNode*>(decl.get())) {
            varDecl->accept(*this);
        }
    }
    emitLine("");
    
    // 生成函数/过程声明
    for (auto& decl : node->declarations) {
        if (auto subprog = dynamic_cast<SubprogramNode*>(decl.get())) {
            subprog->accept(*this);
            emitLine("");
        }
    }
    
    // 生成main函数
    generateMainFunction(node->body.get());
}

void CodeGenerator::visit(IfStmtNode* node) {
    emit("if (");
    node->condition->accept(*this);
    emitLine(") {");
    
    indent();
    node->thenBranch->accept(*this);
    dedent();
    
    if (node->elseBranch) {
        emitLine("} else {");
        indent();
        node->elseBranch->accept(*this);
        dedent();
    }
    
    emitLine("}");
}

void CodeGenerator::visit(ForStmtNode* node) {
    // for i := start to end do body
    // 转换为: for (i = start; i <= end; i++) { body }
    
    emit("for (");
    emit(node->loopVar + " = ");
    node->startValue->accept(*this);
    emit("; ");
    emit(node->loopVar);
    emit(node->isDownto ? " >= " : " <= ");
    node->endValue->accept(*this);
    emit("; ");
    emit(node->loopVar);
    emit(node->isDownto ? "--" : "++");
    emitLine(") {");
    
    indent();
    node->body->accept(*this);
    dedent();
    
    emitLine("}");
}

void CodeGenerator::visit(SubprogramNode* node) {
    // 生成函数/过程定义
    if (node->returnType) {
        // 函数
        emit(mapType(node->returnType.get()) + " ");
    } else {
        // 过程
        emit("void ");
    }
    
    emit(node->name + "(");
    
    // 参数列表
    for (size_t i = 0; i < node->parameters.size(); i++) {
        auto& param = node->parameters[i];
        if (i > 0) emit(", ");
        
        std::string typeStr = mapType(param->type.get());
        if (param->isVar) {
            typeStr += "*";  // var参数转为指针
        }
        
        for (size_t j = 0; j < param->identifiers.size(); j++) {
            if (j > 0) emit(", ");
            emit(typeStr + " " + param->identifiers[j]);
        }
    }
    
    emitLine(") {");
    indent();
    
    // 函数返回值变量
    if (node->returnType) {
        emitLine(mapType(node->returnType.get()) + " " + node->name + "_result;");
    }
    
    // 局部变量
    for (auto& decl : node->localDecls) {
        decl->accept(*this);
    }
    
    // 函数体
    node->body->accept(*this);
    
    // 返回语句
    if (node->returnType) {
        emitLine("return " + node->name + "_result;");
    }
    
    dedent();
    emitLine("}");
}

std::string CodeGenerator::mapType(TypeInfo* type) {
    switch (type->getKind()) {
        case TypeInfo::Kind::INTEGER:
            return "int";
        case TypeInfo::Kind::REAL:
            return "double";
        case TypeInfo::Kind::CHAR:
            return "char";
        case TypeInfo::Kind::BOOLEAN:
            return "int";  // 用int表示boolean
        case TypeInfo::Kind::ARRAY:
            // 处理数组类型
            auto arrayType = static_cast<ArrayType*>(type);
            return mapType(arrayType->elementType);
        // ... 其他类型
    }
}
```

## 3. 数据流设计

### 3.1 编译流程

```
1. 读取源文件 → 字符串
2. 词法分析 → Token流
3. 语法分析 → AST
4. 语义分析 → 标注的AST + 符号表
5. 代码生成 → C代码字符串
6. 写入目标文件
```

### 3.2 主控程序设计

```cpp
class Compiler {
private:
    ErrorHandler errorHandler;
    
public:
    bool compile(const std::string& inputFile, const std::string& outputFile) {
        // 1. 读取源文件
        std::string source = readFile(inputFile);
        
        // 2. 词法分析
        Lexer lexer(source);
        std::vector<Token> tokens = lexer.tokenize();
        
        if (errorHandler.hasError()) {
            errorHandler.printAll();
            return false;
        }
        
        // 3. 语法分析
        Parser parser(tokens, errorHandler);
        auto ast = parser.parse();
        
        if (errorHandler.hasError()) {
            errorHandler.printAll();
            return false;
        }
        
        // 4. 语义分析
        SemanticAnalyzer analyzer(errorHandler);
        analyzer.analyze(ast.get());
        
        if (errorHandler.hasError()) {
            errorHandler.printAll();
            return false;
        }
        
        // 5. 代码生成
        CodeGenerator generator(analyzer.getSymbolTable());
        std::string cCode = generator.generate(ast.get());
        
        // 6. 写入文件
        writeFile(outputFile, cCode);
        
        std::cout << "Compilation successful!" << std::endl;
        return true;
    }
};

int main(int argc, char* argv[]) {
    if (argc < 2) {
        std::cerr << "Usage: pascal-compiler <input.pas> [-o <output.c>]" << std::endl;
        return 1;
    }
    
    std::string inputFile = argv[1];
    std::string outputFile = "output.c";
    
    // 解析命令行参数
    for (int i = 2; i < argc; i++) {
        if (std::string(argv[i]) == "-o" && i + 1 < argc) {
            outputFile = argv[i + 1];
            i++;
        }
    }
    
    Compiler compiler;
    bool success = compiler.compile(inputFile, outputFile);
    
    return success ? 0 : 1;
}
```

## 11. 关键技术难点及解决方案

### 11.1 类型系统映射
**难点**: Pascal的类型系统与C不完全对应
**解决方案**:
- 子界类型映射为基础类型
- 枚举类型映射为整型常量
- 记录类型映射为struct

### 11.2 参数传递
**难点**: Pascal的var参数（引用传递）
**解决方案**: 转换为C的指针参数

### 11.3 函数返回值
**难点**: Pascal通过赋值函数名返回值
**解决方案**: 创建临时变量存储返回值

### 11.4 数组索引
**难点**: Pascal数组可以有任意下界
**解决方案**: 生成索引转换代码

```pascal
arr: array[5..10] of integer;
arr[7] := 10;
```
转换为:
```c
int arr[6];  // 大小为10-5+1=6
arr[7-5] = 10;  // 索引转换
```
